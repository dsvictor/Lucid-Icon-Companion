# Changelog

## 0.2.0 — Development

- Added full upstream Lucide tag metadata to the local catalogue.
- Added multi-term search across icon names and tags.
- Added tag-group filtering.
- Added Favorites and Recent views with persistent history.
- Added keyboard navigation and Cmd+F search focus.
- Added explicit canvas X/Y placement and a FigCraft connection test.
- Moved FigCraft control operations to background threads.
- Made catalogue updates stage before replacing the current cache.
- Added safe validation for SVG colour values.
- Added tests for search, favorites, recent history and SVG colour parsing.
- Added Linux and Windows compile/test jobs alongside macOS Apple Silicon packaging.

## 0.1.0 — Initial development build

- Added native desktop shell and initial SVG browser.
- Added Lucide package download and SVG cache.
- Added SVG preview, export and clipboard support.
- Added FigCraft control client and Apple Silicon DMG packaging.
